## Errors found → fix applied

1. **RL throughput token count** (§3.10). Before: "`seq_len` … (the packed row length)". After: rank 0's first micro-batch length. Bins are variable, so the count is an extrapolation, and the frozen attention $T$ is step 1's first bin. Cites: `train.py:292, 623-629`, `batch.py:690-893`.
2. **Attention FLOPs use $h/H$, not `head_dim`** (§3.10, Gotcha 8, §8). Attention FLOPs are halved for Qwen3; the unit-test constant encodes it (`perf.py:182-194`; `test_perf.py:8-35`).
3. **RL in-orchestrator eval is not version-pinned** (§3.9.3, Invariant 10, §8). Before: §8 said "eval epochs pinned to one policy version". After: only SFT online eval and standalone eval are pinned; RL logs a min-version lower bound (`dispatcher.py:450-457, 532`; `orchestrator.py:923-928`).
4. **Eval `cancelled/mean`** (§3.9.3). After: always 0.0 from metrics; the runner overwrites it only on a cut (`runner.py:278-286`; `metrics.py:526-546`).
5. **`None` → 0.0 on both subsets**, not only `all` (Gotcha 5; `metrics.py:182`). Also added: single-element `std` is NaN.
6. **Live buffer trim** (§3.5). After: trims to the newest 10k deltas (`dispatcher.py:376-377`).
7. **Port-8000 clash** (Gotcha 12, §3.13, §4.4). Now exact: the router binds `0.0.0.0:server.port`, the engine goes to 8100, and whichever binds second fails, normally the trainer's `HTTPServer` with `OSError` at startup. Only single-node `rl`. Router Prometheus port `server.port+21000` added.
8. **Shared `[monitors.file]` leaves** (§4.5). `rl --no-monitors.file` works (presence pass handles the `"None"` string, `validation.py:166-179`). Newly found: only `path` propagates (`:107-108`), so shared `chunk_bytes`/`compress`/`float_decimals` are silently ignored.
9. **W&B non-shared fallback** (§3.7). `WANDB_MODE=offline|disabled` (set by CI) → trainer and orchestrator each create their own run. SFT shared mode only when `[eval]` is configured.
10. **CI layout** (§3.19). `make_dashboard_test` is in 6 modules, not "most"; gsm8k_eval is a no-GPU Prime-Inference test; nightly-fft resolved (hosted `prime train` dispatch of the newest GHCR dev image, fire-and-forget).
11. **Resume `RESUMABLE` fnmatch** (Gotcha 17). `*` crosses dots, so deeper env leaves with the same names are also resumable.
12. Gotcha 22 reworded: the docstring is stale; the inline comment explains the 15%.
13. Open questions: removed resolved Q3 (RANK leak), Q7 (nightly-fft), Q9 (`--no-monitors.file`); added `vllm-router` `/liveness` passthrough and the finisher/trailing-rows race.
