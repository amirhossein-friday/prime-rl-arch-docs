## Ledger items
- **A/H — does a `[tokenizer]` override reach the renderer?** CONFIRMED (static, plus a runtime probe of the resolution half): it does **not**. Validator key = `tokenizer.name` (`configs/orchestrator.py:609-615`, `715`). Renderer = `load_tokenizer(TrainClientConfig.renderer_model_name)` with `renderer_model_name = config.model.name` (`orchestrator.py:199-205` → `clients.py:85-91` → `setup_client` `:259-280` → `train.py:281-286`). The orchestrator's `setup_tokenizer(config.tokenizer)` only goes to `TrainSink` (`orchestrator.py:192`, `371`). Probe: `load_tokenizer(<local Qwen3-0.6B snapshot>)` keeps the path as `name_or_path` → map miss → `DefaultRenderer` (`supports_tools=False`). `chat_template` overrides affect no renderer, in RL or in SFT.
- **C (F/H) — frozen-source node logprobs:** RESOLVED. `GenerationSource.sampling_args` pops `logprobs` (`generation_source.py:43-49`), but `generate()` re-forces `logprobs=1` and strictly validates them (`client.py:310-312`, `137-188`). `node.logprobs` is therefore the frozen engine's real sampled logprobs (`graph.py:911`), not zeros. Requirement: the frozen endpoint must serve vLLM `/inference/v1/generate` with `token_id:N` logprobs, otherwise every turn → Malformed → 502.
- **C (F/H) — is_content population:** CONFIRMED. The renderer emits a full-prompt `is_content` (render, or bridge with the prior portion False). `response_from_generate` forwards `attribution.is_content` (`train.py:165`). `_commit_turn` slices it per new input node only when its length equals `prompt_ids`; the assistant node gets gen-prompt False + completion True; otherwise `[]` (`graph.py:784-786`, `885`, `907-909`). `[]` comes from DefaultRenderer or an offset-less tokenizer.
- **Renderer pool location:** CONFIRMED in the env-server worker. The interception server (in-process, `interception/__init__.py:68-71`, `agent.py:330`) owns one `TrainClient` per distinct `ClientConfig` JSON (`server.py:356-366`). The pool is a class-level dict per process, keyed `(model, cfg json, kwargs json)`. There are ≤256 in-flight turns per slot, first-fit. `grow` is single-flight under a per-key `asyncio.Lock` re-minted per loop. Encode runs via `asyncio.to_thread` under a per-slot `threading.Lock`.
- **B/C — frozen sources reuse the policy renderer config; OPSD uses its own `algo.renderer`:** CONFIRMED (`envs.py:257`, `generation_source.py:36`, `algo/base.py:18-32`; `configs/algorithm.py:338-342`, `opsd.py:47-54`). No validator covers either.
- **D — SFT tokenizer / ensure_final_stop / sampled_mask:** CONFIRMED (`sft/train.py:152`, `sft/data.py:340-367`, `base.py:1679-1735`). `role_to_mask` is None when `loss_mask.assistant` (sampled_mask gating), and non-assistant roles go through `content_sft_roles`.
- **E — `/generate` response fields:** the client side is confirmed as read (`client.py:353-423`). Server semantics belong to E.
